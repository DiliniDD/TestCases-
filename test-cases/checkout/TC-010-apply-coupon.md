---
id: TC-010
title: Apply a valid coupon code at checkout
priority: medium
module: checkout
automated: false
tags: [checkout, discounts]
---

**Preconditions:** Cart contains at least one eligible item. A valid, unused coupon code exists.

**Steps:**
1. Add an eligible item to the cart and proceed to checkout.
2. Enter the valid coupon code in the discount field.
3. Click Apply.

**Expected result:** The discount is applied and the order total updates to reflect the coupon value.
